ENGINEERING SPECIFICATION // CRYPTOGRAPHIC RESEARCH

Technical Approach: Cryptographic Proof Engine

LEDGER PROTOCOL ALGORITHM

Merkle-Chained Hash Verification

Every state change generates a deterministic block hash computed over its entire antecedent history:

H_i = SHA-256( Seq_i ‖ Time_i ‖ Actor_i ‖ Event_i ‖ Data_i ‖ H_{i-1} )

Recomputed in linear time \(O(N)\). If a single historical record is corrupted, the verification engine detects the exact sequence number instantly.

ARCHITECTURE SYSTEM CORE

Zero-Dependency Native Backend

  • Built-in SQLite Engine: Native Node.js `node:sqlite` with Write-Ahead Logging (WAL) for atomic concurrency.
  • Memory-Only Token Transport: `X-Token` authentication; zero persistence in browser `localStorage` prevents XSS token theft.
  • Sliding-Window Rate Limiting: Adaptive token-bucket throttling responding with HTTP 429 and `Retry-After`.
  • Heuristic Verdict Engine: Automated attack classification into `SAFE`, `BLOCKED`, `REFUSED`, and `COMPROMISED`.
